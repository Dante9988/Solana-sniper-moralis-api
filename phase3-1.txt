## Supported Moralis functionality

Verify request and response handling for currently supported APIs before retaining them:

* GET /token/{network}/{address}/metadata
* GET /token/{network}/{address}/price
* POST /token/{network}/prices
* GET /token/{network}/{address}/swaps
* supported token-pair endpoint
* GET /token/{network}/pairs/{pairAddress}/stats
* supported OHLC/candlestick endpoints
* supported Universal Token API endpoints already used by the repository

For every retained endpoint:

* use the documented host and path
* use X-Api-Key without logging it
* validate HTTP status before JSON parsing
* distinguish TOKEN_NOT_FOUND from ENDPOINT_REMOVED
* classify 401/403 as authentication/permission failure
* classify 404 accurately
* retry 429 and retryable 5xx only
* do not retry ordinary 4xx responses
* enforce timeout and maximum response size
* validate responses with existing schemas or minimal Zod schemas
* tolerate missing/null fields
* store source and retrieval timestamp

Do not introduce Moralis Onchain Skills or another Moralis AI feature. Anthropic remains the synthesis provider.
